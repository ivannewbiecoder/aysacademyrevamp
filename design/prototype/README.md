AYS Science Academy redesign prototype

Start with index.html, then use the navigation to explore Training Camp, program details, articles, news, Bank Soal, Tryout, and Diagnostik.

This is a static design prototype. It does not connect to AYS accounts, store student answers, or process diagnostic results. Diagnostic, Tryout, article, question-bank, email, and WhatsApp actions link to the existing AYS services where available.

Program details follow information found on the public AYS pages. Batch dates and prices are not shown because those details need confirmation. The official Training Camp page describes a hybrid format; the homepage has conflicting online-only copy, so this prototype labels format by phase and directs visitors to confirm the active batch.
